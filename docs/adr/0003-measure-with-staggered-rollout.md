# 3. Measure impact with staggered rollouts, not usage dashboards

Status: accepted

Use cases are launched in waves; the countries not yet launched are the comparison (difference in
differences with not-yet-treated controls, bootstrap over countries). The simulated organisation was
built with the two biases real deployments have (people use the tool on easier cases; faster people adopt
first) so the measurement can be checked against the truth: the staggered estimate's interval contains it,
the naive comparison overstates it. Central teams without a control group get a before/after figure with
its caveat; use cases without pre-launch cases get none.
